# Amazon Products Data Analysis

## Project Overview

This project explores Amazon product data to understand product categories, pricing, discounts, and customer ratings. It demonstrates a data analysis workflow using Python and Power BI, from data understanding and cleaning to exploratory analysis and visualization.

## Objectives

- Understand the structure and quality of the dataset.
- Clean and prepare data for analysis.
- Explore product categories, prices, discounts, and ratings.
- Identify patterns and trends in product data.
- Present key findings through an interactive Power BI dashboard.

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Power BI
- Git and GitHub

## Project Workflow

1. **Data Understanding:** Examine the dataset structure, columns, data types, and missing values.
2. **Data Cleaning:** Handle data quality issues and convert columns into appropriate data types.
3. **Exploratory Data Analysis (EDA):** Analyze product categories, prices, discounts, and customer ratings.
4. **Data Visualization:** Create visualizations to explore patterns and relationships.
5. **Dashboard Development:** Build a Power BI dashboard to present the analysis.

## Project Structure

| File | Description |
|---|---|
| `data_understanding.py` | Examines the dataset structure and data quality. |
| `cleaning.py` | Cleans and prepares the data for analysis. |
| `analysis.py` | Performs data analysis and explores key metrics. |
| `visualization.py` | Creates visualizations to support the analysis. |
| `powerbi/Amazon_Dashboard.pbix` | Power BI dashboard containing the visual analysis. |

## Dataset

The dataset contains Amazon product information, including product categories, prices, discounts, ratings, and customer reviews.

The original dataset is not included in this repository. Please refer to the original source for dataset access and licensing information.

## Key Areas of Analysis

- Product category distribution
- Actual prices versus discounted prices
- Discount percentages across products
- Customer rating distribution
- Relationships between product pricing, discounts, and ratings

## Power BI Dashboard

The Power BI dashboard presents product data through visualizations and key metrics to make patterns easier to explore and understand.

To explore the dashboard, open `powerbi/Amazon_Dashboard.pbix` using Microsoft Power BI Desktop.
